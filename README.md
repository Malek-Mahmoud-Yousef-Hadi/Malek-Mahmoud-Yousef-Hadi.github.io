# Malek Hadi — Ghost Operator Portfolio

This is a static HTML, CSS, and Vanilla JavaScript cybersecurity portfolio designed for GitHub Pages. It does not require PHP, a database, a build step, or server-side processing.

## Section order

The portfolio contains the following sections in professional-priority order:

1. `ABOUT_ME`
2. `CONTACT_INFO`
3. `LEARNING_ROADMAP`
4. `NEXT_LEVEL_GOALS`
5. `MY_CERTIFICATES`
6. `MY_CV`
7. `PROFESSIONAL_EXPERIENCE`
8. `PRACTICAL_PROJECTS`

The roadmap includes an `OSCP` node connected from `eJPTv2`. The practical-project list replaces `IDOR Real Website` with `Web Exploitation — CYLab Security Academy / PicoCTF`.

## Adding professional-experience evidence

Place the two work-evidence PDFs in `work_experience/` with these exact filenames:

- `full-web-penetration-testing-real-website.pdf`
- `black-box-internal-network-penetration-testing.pdf`

The `[ VIEW_WORK ]` buttons use the same document-preview lightbox as the CV section. If a filename or extension changes, update the matching entry in `assets/js/config.js`.

## GitHub Pages deployment

Upload the project contents to a GitHub repository, open **Settings → Pages**, select the deployment branch and the repository root as the source, and save. The site can then be accessed through the GitHub Pages URL generated by GitHub.
